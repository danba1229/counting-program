차량 회전 궤적 검토 프로그램 (SweptPathChecker)

[실행]
  SweptPathChecker.exe 를 더블클릭합니다. Python 설치는 필요 없습니다.
  이 폴더(_internal 포함)를 통째로 두고 실행해야 합니다. exe 파일만 따로 옮기면 실행되지 않습니다.
  처음 실행 시 Windows가 "PC 보호" 경고를 띄우면 [추가 정보] → [실행]을 누르세요.
  (서명되지 않은 직접 만든 프로그램이라 표시되는 경고입니다.)

[처음 써보기]
  파일 → 샘플 도면 열기 → 3. 경로 탭 → 출발점(누른 채 끌어 방향 지정) → 경유점 → 목적지 → [회전 검토 실행]

[사용 순서]
  1. 도면: DXF 열기 → 단위(보통 mm) 확인 → 장애물 레이어 선택 (검은 선 = 장애물)
     DWG는 GstarCAD가 설치된 PC면 바로 열립니다(없으면 무료 ODA File Converter 설치, 또는 CAD에서 DXF로 저장).
  2. 차량: 차량 선택, 필요하면 [제원 편집 / 새 차량]
  3. 경로: 출발점(앞축 중심) → 경유점 → 목적지. 후진 구간은 '후진'을 고른 뒤 찍습니다.
  4. [회전 검토 실행] → 4. 결과 탭에서 판정 확인
     [보고서 저장 (PDF)]: 궤적 그림 + 상세 + 충돌 위치 확대도 / [그림 저장 (PNG)] / DXF / 글자 보고서(txt)
     빨간 원 = 충돌(차체가 닿음), 주황 원 = 여유폭 부족(닿지는 않음), '최소 이격' = 장애물까지 가장 가까운 거리
  [모든 차량 비교]: 같은 경로로 모든 차량을 한 번에 검토해 표로 비교 (행 두 번 클릭: 그 차량 궤적 보기, CSV 저장)

[장애물 레이어 고르기]
  [도면에서 클릭해 장애물 레이어 켜기/끄기] → 선 위에 마우스: 같은 레이어가 주황색 강조 → 클릭: 장애물 켜기/끄기
  [레이어 설정 저장/불러오기]: 고른 레이어를 파일로 저장해 다른 도면에 적용

[선·레이어 지우기] (프로그램 안에서만, 원본 도면은 그대로)
  [✂ 도면에서 선 지우기] → 클릭: 선 1개 / Shift+클릭: 레이어 전체 / 끌기: 사각형 안의 선
  레이어 목록 오른쪽 클릭: 레이어 지우기·되살리기,  Ctrl+Z: 되돌리기,  [지운 선 모두 복원]

[잘못 찍었을 때]
  점을 누른 채 끌기: 위치 이동 / 화살표 끝 끌기: 방향 수정
  목록에서 더블클릭: 좌표·방향을 숫자로 수정
  Ctrl+Z: 되돌리기 (초기화도 되돌릴 수 있음) / 화면 오른쪽 위 [경로 초기화]

[화면 조작]
  마우스 휠: 확대/축소,  휠 버튼 또는 오른쪽 버튼 끌기: 화면 이동,  Shift+끌기: 방향 15° 단위

[자체 점검]
  명령 프롬프트에서  SweptPathChecker.exe --selftest  실행 → 같은 폴더에 selftest_result.txt 생성

[파일]
  user_vehicles.json : 사용자가 저장한 차량 제원 (exe 옆에 자동 생성)
