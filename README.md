# 보행 통행량 카운터

폴더 안의 모든 영상을 읽어서, 사용자가 지정한 직선을 기준으로 객체의 `IN / OUT` 통행을 집계하는 Python 데스크톱 앱입니다.

이 버전은 다음 3가지를 반영합니다.

- 집계 시간 구간을 영상 좌하단에 표시되는 시간 오버레이 기준으로 계산
- 사각형 ROI 대신 직선 하나를 기준으로 선 넘기 `IN / OUT` 판정
- 폴더 단위로 여러 영상 일괄 분석
- 보행자, 자전거/킥보드, 오토바이, 승용차, 트럭 분리 집계

추가로 현재 버전은 가능한 경우 `ONNX Runtime + GPU`를 자동 사용하고, 불가능하면 CPU로 안전하게 내려갑니다.
현재 Windows 환경에서는 `DirectML` 경로가 기본 GPU 가속 경로입니다.

## 현재 구성

- [`desktop_app.py`](./desktop_app.py)
  - Tkinter 데스크톱 UI
  - 폴더 안 모든 영상 자동 탐색
  - 첫 영상 프레임 미리보기
  - 직선 카운팅 라인 지정
  - 보행자 / 자전거(킥보드 포함 표시) / 오토바이 / 승용차 / 트럭 감지
  - 간단 추적
  - 선 넘기 `IN / OUT` 판정
  - 1시간 단위 집계
  - 15분 단위 재집계 저장
  - CSV / XLSX 저장
- [`models`](./models)
  - YOLOX ONNX 모델
  - MediaPipe PersonDet ONNX 모델
- [`requirements.txt`](./requirements.txt)
  - 필요한 Python 패키지

## 사용 순서

1. `영상 폴더 선택`을 눌러 분석할 영상들이 들어 있는 폴더를 고릅니다.
2. 첫 영상의 첫 프레임이 보이면 두 점을 드래그해서 카운팅 선을 그립니다.
3. `카운팅 대상 선택`에서 집계할 종류만 체크합니다.
4. 필요하면 옵션을 조정합니다.
5. `폴더 분석 시작`을 누릅니다.
6. 오른쪽 표에서 선택한 종류의 시간대별 `IN / OUT` 집계를 확인합니다.
7. 필요하면 `결과 저장`으로 결과와 이벤트 로그를 함께 저장합니다.

## IN / OUT 기준

- 선의 시작점에서 끝점 방향으로 본다고 가정합니다.
- 그 기준에서 오른쪽에서 왼쪽으로 선을 넘으면 `IN`
- 왼쪽에서 오른쪽으로 선을 넘으면 `OUT`

반대로 쓰고 싶으면 선을 반대 방향으로 다시 그리면 됩니다.

## 시간 집계 방식

- 영상 좌하단 시간 오버레이를 읽어 시간 문자열을 추정합니다.
- 읽은 시간이 정상 파싱되면 그 시간을 기준으로 시간 구간을 만듭니다.
- 일부 프레임에서 OCR이 흔들리면 직전 인식 시간과 경과 시간을 이용해 보정합니다.

## 옵션 설명

- `샘플링 간격(초)`
  - 몇 초 간격으로 프레임을 검사할지 정합니다.
  - 낮을수록 더 촘촘하지만 느려집니다.
- `분석 속도`
  - `1x / 1.5x / 2x / 3x` 중 선택할 수 있습니다.
  - 배속이 높을수록 실제 샘플링 간격이 커져 더 빨라지지만 혼잡 장면 정확도는 떨어질 수 있습니다.
- `트랙 연결 거리(px)`
  - 같은 사람으로 이어 붙일 최대 중심점 거리입니다.
- `재카운트 방지 시간(초)`
  - 같은 트랙이 짧은 시간 안에 다시 카운트되는 것을 줄입니다.
- `감지 신뢰도`
  - YOLOX 감지 점수 임계값입니다.
- `HOG 보조 축소 비율`
  - 딥러닝 감지기가 실패했을 때 fallback HOG 검출에서 쓰는 축소 비율입니다.

## 감지기 우선순위

1. YOLOX
2. MediaPipe PersonDet
3. OpenCV HOG fallback

감지기 상태에 `ONNX Runtime / GPU(DirectML)` 또는 `ONNX Runtime / GPU(CUDA)`가 보이면 GPU가 실제로 사용 중인 상태입니다.

## 저장 형식

- `.xlsx`
  - `hourly_counts`, `quarter_hour_counts`, `events` 시트를 함께 저장합니다.
- `.csv`
  - 선택한 파일에는 1시간 단위 집계를 저장합니다.
  - 같은 위치에 `_15min.csv` 파일을 추가로 만들어 15분 단위 재집계를 저장합니다.

## 주의 사항

- 좌하단 시간 오버레이 폰트가 너무 특이하거나 작으면 OCR이 흔들릴 수 있습니다.
- 여러 영상이 같은 카메라 구도와 비슷한 화면 구성을 공유한다는 가정으로 설계되어 있습니다.
- 선 넘기 판정은 현재 "트랙 중심점 이동 경로가 지정한 선분을 가로지르는가" 기준입니다.
- 군중이 아주 많거나 가림이 심하면 중복/누락 카운트가 생길 수 있습니다.
