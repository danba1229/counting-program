# 차량 회전 궤적 검토 프로그램

도면(DXF/DWG)을 불러오고 차량을 고른 뒤 **출발점 → 경유점 → 목적지**를 찍으면,
차량이 그 경로로 회전할 수 있는지(벽·기둥 충돌, 여유폭, 목표 도달, 잭나이프)를 자동으로 판정하는 프로그램입니다.

CAD 프로그램 안에서 돌아가는 플러그인이 아니라 **독립 실행 프로그램**입니다.
그래서 AutoCAD 버전과 관계없이 동작하고, 결과를 DXF로 내보내 어떤 CAD에서든 겹쳐 볼 수 있습니다.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 도면 | DXF 직접 읽기, DWG는 무료 ODA File Converter가 설치되어 있으면 자동 변환 |
| 장애물 | 레이어 단위로 선택 (선, 폴리선, 원호, 원, 스플라인, 블록(기둥 등), 솔리드, 해치 경계) |
| 차량 | 설계기준자동차(소형·대형·세미트레일러) + 미니버스(카운티 장축) 기본 제공, 제원 편집·사용자 차량 저장 |
| 경로 | 출발점(드래그로 차량 방향), 경유점, 목적지(드래그로 도착 방향), **전진/후진 혼합** (여러 번 꺾기) |
| 판정 | 차체·트레일러와 장애물 충돌, 여유폭 부족, 목표점/방향 도달 실패, 트레일러 잭나이프 |
| 결과 | 차체 궤적(스웹트 패스), 여유폭 외곽, 바퀴·모서리 궤적, 차량 윤곽, 충돌 위치, 위치 슬라이더 |
| 저장 | 원본 도면 + 결과 레이어 DXF, 결과만 DXF, 검토 보고서(txt), 작업 파일(json) |

## 실행 파일(exe)로 쓰기 — Python 설치 불필요

1. GitHub 저장소의 **Actions → Build SweptPathChecker (Windows exe)** 에서 최근 실행을 열고,
   맨 아래 **Artifacts** 의 `SweptPathChecker-windows` 를 내려받습니다.
2. 압축을 풀고 `SweptPathChecker\SweptPathChecker.exe` 를 실행합니다.
   - `_internal` 폴더와 함께 있어야 합니다. exe만 따로 옮기면 실행되지 않습니다.
   - 서명되지 않은 프로그램이라 처음에 "Windows의 PC 보호" 창이 뜰 수 있습니다. **추가 정보 → 실행**을 누르세요.
3. `파일 → 샘플 도면 열기`로 바로 시험해 볼 수 있습니다.

`SweptPathChecker.exe --selftest` 를 실행하면 계산·저장·화면 동작을 자체 점검하고 `selftest_result.txt` 를 남깁니다.
`swept-path-checker/` 아래 파일이 바뀌어 푸시될 때마다 Windows 서버에서 빌드, 테스트, exe 자체 점검이 자동으로 실행됩니다.

### 직접 빌드하기

```powershell
pip install -r requirements.txt pyinstaller
pyinstaller --noconfirm SweptPathChecker.spec
```

결과물: `dist\SweptPathChecker\` 폴더

## exe 다운로드가 브라우저에서 막힐 때

Chrome은 코드 서명이 없고 다운로드 이력이 적은 exe를 "흔하지 않은 파일"로 보고 자동 차단합니다(파일에 문제가 있다는 뜻은 아닙니다).

**방법 1: 차단 해제 (가능한 경우)**
`chrome://downloads` 에서 해당 항목의 **계속 / 위험한 파일 유지**를 누릅니다. 회사에서 관리하는 Chrome은 이 버튼이 없을 수 있습니다.

**방법 2: exe 없이 실행 (권장)**
1. https://www.python.org/downloads/ 에서 Python 3.12 설치 (서명된 정식 설치 파일)
   - 설치 첫 화면에서 **Add python.exe to PATH** 체크
2. Actions 실행 결과의 Artifacts에서 `SweptPathChecker-source` (실행 파일이 없는 소스 묶음)를 내려받아 압축 해제
3. `시작하기.pyw` 더블클릭
   - 처음 한 번은 필요한 부품을 자동 설치 (1~3분, 인터넷 필요)
   - 다음부터는 바로 실행

회사망에서 부품 설치(pip)가 막히면 전산 담당자에게 `pypi.org`, `files.pythonhosted.org` 접속 허용을 요청하세요.

## Python으로 실행 (Windows)

1. Python 3.10 이상 설치 (설치 시 "Add python.exe to PATH" 체크)
2. 이 폴더에서 패키지 설치

```powershell
pip install -r requirements.txt
```

3. 실행: `run_app.bat` 더블클릭 또는

```powershell
python app.py
```

샘플 도면: `samples/sample_parking.dxf` (지하주차장 통로 + 90° 코너 + 기둥)

### DWG 파일을 쓰려면

DWG는 형식이 공개되어 있지 않아 직접 읽을 수 없습니다. 둘 중 하나를 쓰세요.

- **ODA File Converter** (무료)를 설치하면 DWG를 그대로 열 수 있습니다. 프로그램이 자동으로 찾아 변환합니다.
- CAD에서 `다른 이름으로 저장 → DXF`로 저장한 파일을 엽니다.

## 사용 방법

1. **1. 도면** 탭: `도면 열기` → 단위 확인(보통 mm) → 장애물로 볼 레이어 선택
   - 치수·문자·해치·중심선·주차구획 이름이 들어간 레이어는 기본적으로 장애물에서 빠집니다.
   - 검은 선 = 장애물, 회색 선 = 장애물 아님
   - **도면에서 바로 고르기**: `🖱 도면에서 클릭해 장애물 레이어 켜기/끄기` → 선 위에 마우스를 올리면 같은 레이어 선이 주황색으로 강조되고 이름이 표시됨 → 클릭하면 장애물 ↔ 장애물 아님 전환
   - **레이어 설정 저장/불러오기**: 고른 장애물 레이어 목록을 파일로 저장해 같은 사업의 다른 도면에 적용 (이 도면에 없는 레이어는 건너뜀)
2. **2. 차량** 탭: 차량 선택 (필요하면 `제원 편집 / 새 차량`)
3. **3. 경로** 탭
   - `출발점`: 차량 **앞축 중심** 위치를 누르고, 차량이 바라볼 방향으로 끌었다 놓기 (Shift: 15° 단위)
   - `경유점`: 클릭할 때마다 추가
   - `목적지`: 클릭(방향 무관) 또는 끌어서 도착 방향 지정
   - **후진**: 진행 방향을 `후진`으로 바꾼 뒤 찍은 점부터 후진 구간입니다. 전진↔후진이 바뀌는 점에서 정지 후 방향을 바꿉니다(여러 번 꺾기).
   - **잘못 찍었을 때**
     - 점 위치 수정: 찍은 점을 누른 채 끌면 이동 (어느 도구를 고른 상태에서도 가능)
     - 방향 수정: 출발점·목적지 화살표 끝을 끌어 회전 (Shift: 15° 단위)
     - 숫자로 수정: 목록에서 점을 더블클릭하거나 `선택 점 수정` → x, y, 방향, 전진/후진 입력
     - 되돌리기: `Ctrl+Z` 또는 `↶ 되돌리기` (최근 100단계, 초기화도 되돌릴 수 있음)
     - 경로 초기화: 도면 화면 오른쪽 위 또는 경로 탭의 `경로 초기화`
4. `▶ 회전 검토 실행` → **4. 결과** 탭에서 판정과 구간별 결과 확인, 슬라이더로 차량 위치 확인
5. 결과를 DXF나 보고서로 저장

### 경로 기준점

| 진행 | 경로를 따라가는 점 |
|---|---|
| 전진 | 앞축 중심 |
| 후진 (단일차량) | 뒷축 중심 |
| 후진 (세미트레일러) | 트레일러 축 중심 |

경유점은 "이 점을 지나가라"는 운전 목표입니다. 차량은 조향 한계와 핸들 조작 속도 안에서 최대한 따라갑니다.
경로 이탈량은 결과에 [주의]로 표시됩니다.

### 판정 기준

- **회전 불가**: 차체(또는 트레일러)가 장애물에 닿거나 여유폭 안으로 들어옴 / 목표점을 허용오차 안으로 지나지 못함 / 목적지 도착 방향 오차 초과 / 트레일러 꺾임각 한계 초과
- **주의**: 지정 경로에서 1 m 이상 벗어남, 핸들을 끝까지 꺾은 상태로 주행한 거리

## 차량 제원

| 차량 | 폭 | 길이 | 축간거리 | 앞내민 | 뒷내민 | 최소회전반경 | 비고 |
|---|---|---|---|---|---|---|---|
| 소형자동차 | 1.7 | 4.7 | 2.7 | 0.8 | 1.2 | 6.0 | 설계기준자동차 |
| 미니버스(카운티 장축) | 2.035 | 7.71 | 4.085 | 1.2* | 2.425* | 7.6* | *추정값, 제작사 제원표로 확인 필요 |
| 대형자동차 | 2.5 | 13.0 | 6.5 | 2.5 | 4.0 | 12.0 | 설계기준자동차 |
| 세미트레일러 | 2.5 | 16.7 | 앞 4.2 / 뒤 9.0 | 1.3 | 2.2 | 12.0 | 설계기준자동차 |

- 단위 m. 최소회전반경은 **바깥쪽 앞바퀴 중심** 기준입니다.
- 윤거(좌우 바퀴 간격), 핸들 조작시간, 세미트레일러의 트랙터 뒷부분 길이와 트레일러 앞 내민길이는 기준에 없어 가정한 값입니다.
- 사용자 차량은 `user_vehicles.json`에 저장됩니다.

## 계산 원리

- **운동학 모델**: 단일차량은 자전거 모델(앞바퀴 조향, 뒷축 기준)입니다. 세미트레일러는 킹핀으로 연결된 트레일러 방향을 함께 적분합니다.
- **최대 조향각**: 바깥 앞바퀴 반경 R, 축간거리 L, 윤거 T에서 `뒷축 중심 반경 Rr = √(R² − L²) − T/2`, `조향각 = atan(L / Rr)`입니다.
- **조향 속도 제한**: 핸들을 끝에서 끝까지 돌리는 시간(차량 제원)과 주행 속도(검토 조건)로 1 m당 조향 변화량을 제한합니다. 정지 상태 조작 허용 시, 출발·방향전환 순간에는 제자리에서 핸들을 돌릴 수 있습니다.
- **경로 추종**
  - 전진: 앞축 기준 Pure Pursuit
  - 후진(단일차량): 뒷축 기준 Pure Pursuit
  - 후진(세미트레일러): 트레일러 축이 경로를 따르도록 목표 꺾임각을 정하고, 트랙터 조향으로 꺾임각을 맞추는 2단 제어
- **충돌 검사**: 0.1 m 간격으로 차체 사각형을 여유폭만큼 키워 장애물 선과 교차 검사합니다(shapely STRtree).

## 한계 및 주의

- 경유점 방식이므로 경로는 사람이 잡아야 합니다. 자동 경로 탐색은 아직 없습니다.
- 세미트레일러 후진은 실제 숙련 운전자보다 보수적으로(불가 쪽으로) 판정될 수 있습니다. 경유점을 더 완만하게 잡아 다시 확인하세요.
- 차체는 평면 사각형으로 봅니다. 차고(높이) 제한, 램프 경사, 범퍼 모서리 라운드는 반영하지 않습니다.
- 결과는 설계 검토 보조용입니다. 최종 판단은 관련 기준과 실제 차량 제원으로 확인하세요.

## 폴더 구성

```
swept-path-checker/
├─ app.py                 Tkinter GUI
├─ 시작하기.pyw            exe 없이 실행 (처음 한 번 부품 자동 설치)
├─ swept_path/
│  ├─ vehicles.py         차량 제원, 기본 차량, 사용자 차량 저장
│  ├─ geometry.py         차체/바퀴 좌표 계산
│  ├─ simulate.py         경로 추종 주행 시뮬레이션 (전진/후진/세미트레일러)
│  ├─ analysis.py         충돌 검사, 궤적 계산, 판정
│  ├─ drawing.py          DXF/DWG 읽기, 레이어·단위 처리 (블록은 한 번만 풀어 재사용)
│  ├─ render.py           도면을 이미지 한 장으로 그리기 (보이는 선만, 확대·이동 미리보기)
│  └─ export.py           DXF/보고서/작업 파일 저장
├─ selftest.py            실행 파일 자체 점검 (--selftest)
├─ SweptPathChecker.spec  PyInstaller 빌드 설정
├─ packaging/             exe와 함께 배포하는 사용법
├─ tools/bench_view.py    화면 반응 속도 측정 (python tools/bench_view.py [도면.dxf])
├─ samples/               샘플 도면 및 생성 스크립트
└─ tests/                 자동 테스트 (python -m pytest)
```
