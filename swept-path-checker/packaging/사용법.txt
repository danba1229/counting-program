차량 회전 궤적 검토 프로그램 (SweptPathChecker)

[실행]
  SweptPathChecker.exe 를 더블클릭합니다. Python 설치는 필요 없습니다.
  이 폴더(_internal 포함)를 통째로 두고 실행해야 합니다. exe 파일만 따로 옮기면 실행되지 않습니다.
  처음 실행 시 Windows가 "PC 보호" 경고를 띄우면 [추가 정보] → [실행]을 누르세요.
  (서명되지 않은 직접 만든 프로그램이라 표시되는 경고입니다.)

[처음 써보기]
  파일 → 샘플 도면 열기 → 3. 경로 탭 → 출발점(누른 채 끌어 방향 지정) → 경유점 → 목적지 → [회전 검토 실행]

[사용 순서]
  1. 도면: DXF 열기 → 단위(보통 mm) 확인 → 장애물 레이어 선택 (검은 선 = 장애물)
     DWG는 무료 ODA File Converter 설치 시 바로 열리고, 아니면 CAD에서 DXF로 저장해서 여세요.
  2. 차량: 차량 선택, 필요하면 [제원 편집 / 새 차량]
  3. 경로: 출발점(앞축 중심) → 경유점 → 목적지. 후진 구간은 '후진'을 고른 뒤 찍습니다.
  4. [회전 검토 실행] → 4. 결과 탭에서 판정 확인, DXF/보고서 저장

[화면 조작]
  마우스 휠: 확대/축소,  휠 버튼 또는 오른쪽 버튼 끌기: 화면 이동,  Shift+끌기: 방향 15° 단위

[자체 점검]
  명령 프롬프트에서  SweptPathChecker.exe --selftest  실행 → 같은 폴더에 selftest_result.txt 생성

[파일]
  user_vehicles.json : 사용자가 저장한 차량 제원 (exe 옆에 자동 생성)
